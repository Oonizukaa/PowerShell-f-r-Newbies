# PowerShell für Einsteiger: Dein erstes System-Checkup-Skript

Dieser Kurs richtet sich an **komplette Anfänger** ohne Programmiererfahrung, zum Beispiel an alle, die eine Ausbildung zum **Fachinformatiker für Systemintegration** anfangen oder sich darauf vorbereiten.

Am Ende hast du ein eigenes PowerShell-Skript geschrieben, das automatisch prüft:

- ob auf deiner Festplatte noch genug Speicherplatz frei ist
- ob wichtige Windows-Dienste laufen

## Was du brauchst

- Einen Windows-PC (PowerShell ist bereits vorinstalliert)
- Etwas Geduld und Lust zum Ausprobieren
- **Keine** Vorkenntnisse

## So funktioniert der Kurs

Jede Lektion besteht aus einer kurzen Erklärung, einer kleinen **Aufgabe** zum Selbstausprobieren und einer **Lösung** zum Aufklappen.

Mach die Aufgabe immer zuerst selbst, bevor du die Lösung anschaust. Fehlermeldungen sind dabei völlig normal: Aus ihnen lernt man am meisten. Am Ende jeder Lektion findest du außerdem die **häufigsten Anfängerfehler**, damit du weißt, worauf du achten musst.
